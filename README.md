## نقاط قوت رقابتی

### ۱. کارایی مکانیکی (‫SAE ~2.0‬)
- پرهٔ جامد بدون سوراخ (سوراخ‌ها کارایی را کاهش می‌دهند)
- لبهٔ دندانه‌دار برای انتقال بهتر اکسیژن
- چیدمان پلکانی پره‌ها
- **نتیجه:** نصف برق مصرفی نسبت به مدل‌های چینی معمولی

### ۲. دوام الکتریکی ⚡
**۸ دلیل اصلی سوختن موتور:**
1. ‫Single-phasing‬ (قطع یک فاز — شایع‌ترین در شبکهٔ روستایی)
2. اضافه‌بار (غوطه‌وری بیش از حد)
3. افت ولتاژ
4. قفل روتور
5. نفوذ رطوبت/نمک به سیم‌پیچی
6. کار ‫24‬ ساعته بدون حاشیهٔ حرارتی
7. فقدان حفاظت
8. خرابی بلبرینگ

**راه‌حل:** برد حفاظت هوشمند موتور
- حفاظت فاز / اضافه‌جریان / ولتاژ
- حفاظت حرارتی ‫PTC‬
- ‫Soft-start‬ یا ‫VFD‬
- **پیام بازاریابی:** «نمی‌سوزد، ضمانت»

### ۳. بهینه‌سازی محلی
- تنظیم ‫RPM / غوطه‌وری / زاویهٔ پره‬ برای شوری خلیج فارس (‫~35 ppt‬)
- این داده را هیچ شرکت چینی ندارد
- اشباع ‫DO‬ در آب خلیج فارس: ‫~6 mg/L‬ (پایین‌تر از آب شیرین)

## داده‌های کلیدی فنی

### ‫SAE‬ (کارایی انتقال اکسیژن)
- طراحی خوب (‫Auburn، پره جامد): ~2.0 kg O₂/kWh‬
- معمولیِ آسیایی/چینی: ‫~1.0–1.4‬
- دیفیوزر حباب ریز در استخرهای کم‌عمق: ‫~1.1‬
- **علت ‫SAE‬ پایین چینی‌ها:** سوراخ در پره‌ها

### سایزینگ (قاعدهٔ ‫Boyd‬)
- ‫1 HP‬ هوادهی به ازای ‫400–500 kg‬ بیومس برداشت
- سیستم فوق‌متراکم (‫100+ PL/m²‬): ‫10–24 HP/ha‬
- سیستم نیمه‌متراکم (‫~60 PL/m²‬): لانگ‌آرم کافی است

### پنجرهٔ بحرانی ‫DO‬
- ساعت ‫04:00–06:00‬ (پایین‌ترین اکسیژن، بدون خورشید)
- ‫DO‬ زیر ‫3.5 mg/L‬ = مرگ‌ومیر
- **نتیجه:** سیستم خورشیدی بدون باتری کار نمی‌کند

### شوری
- بهینهٔ انتقال ‫O₂‬: ‫~30 ppt‬
- آب خلیج فارس: ‫~35 ppt‬ (نیاز به اعتبارسنجی ‫SAE‬ محلی)
- اشباع ‫DO‬ در خلیج فارس: ‫~6 mg/L‬ (بافر کمتر → نیاز به واحدهای بیشتر)
